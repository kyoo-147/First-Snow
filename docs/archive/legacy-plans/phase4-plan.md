# Phase 4 Plan - Safety, Polish, Deploy

## Objective
Hoàn thiện lớp an toàn, tối ưu hiệu năng, chuẩn bị deploy và pilot thực tế.

## Inputs / Prerequisites
- Phase 3 complete
- End-to-end product loop working
- Alert provider credentials available

## Build Items
- Implement alert trigger logic and delivery orchestration
- Add push notification setup and alert history UI
- Finalize consent and privacy copy
- Optimize latency-critical paths
- Run bug bash across browsers and device classes
- Prepare demo data, pilot checklist, and release readiness notes

## Acceptance Checks
- Warning and critical alerts route to the right channels
- Consent flow clearly explains data collection
- Product remains stable during extended test sessions
- Pilot checklist can be executed with known limitations documented

## Risk Watchouts
- Zalo OA setup and approval delays
- Provider outages or partial delivery failure
- Remaining latency or browser edge-case regressions
