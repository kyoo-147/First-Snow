# Review Checklists

## Code Review
- Does the change respect canonical docs?
- Does it preserve ownership and auth safety?
- Does it avoid drifting from phase/task scope?

## Privacy Review
- Does it avoid raw audio/video storage?
- Does it preserve consent clarity?
- Does it avoid unnecessary PII exposure?

## API Review
- Are request/response contracts explicit?
- Are error categories understandable?
- Are async/background behaviors safe and intentional?

## Pilot Readiness Review
- Are browser/device assumptions documented?
- Are alert behaviors understandable and testable?
- Is child-facing UX calm and usable?
