# Snow Accessibility Rules

Snow is for children and may support neurodiverse learners. Accessibility is a product requirement, not polish.

## Text

- Body text minimum: 16px
- Child task prompt: 22px or larger
- Main action labels: 18px or larger
- Avoid long paragraphs in child mode

## Target size

- Preferred minimum target size: 44px by 44px
- Never place tiny controls close together in child mode
- Mic, Stop, Help, and Parent Access must be visually distinct

## Motion

- No flashing
- No fast repeated motion
- Provide calm mode
- Idle animation should be breathing, blinking, or gentle floating only

## Color contrast

- Follow WCAG AA as baseline
- Do not put small purple text on lavender backgrounds
- Do not rely on color alone for status

## Cognitive load

- Child screens must have one primary task
- Mood choices max 4 to 7 depending on age mode
- Lesson answer choices max 4 for young children

## Safety

- Any emergency or grown-up help action must be easy to find
- Parent settings must be protected behind parent access
