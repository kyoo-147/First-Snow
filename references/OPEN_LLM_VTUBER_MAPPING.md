# Open LLM VTuber to Snow Mapping

## Original Open LLM VTuber structure

- Settings panel
- Tabs: General, Live2D, ASR, TTS, Agent, About
- Background image or camera background
- Live2D character stage
- Connection badge
- Subtitle overlay
- AI state pill
- Mic switch
- Interrupt button
- Text input
- WebSocket URL
- Base URL

## Snow mapping

| Open LLM VTuber | Snow |
|---|---|
| Anime Live2D character | Snow 2D companion mascot |
| Classroom background | Cozy child-safe learning room |
| Settings | Companion Settings |
| General tab | Child-friendly general controls |
| Live2D tab | Snow character preset, scale, position |
| ASR tab | Voice recognition settings |
| TTS tab | Calm voice settings |
| Agent tab | Snow persona and safety mode |
| Subtitle | Child-readable Snow subtitle |
| Mic switch | Hold to talk with Snow |
| Interrupt | Stop / pause Snow |
| Chat input | Type your message |
| Connection badge | Connected to Snow |

## Keep from source

- Settings tabs

- WebSocket connection model
- ASR/TTS modularity
- bottom input/control bar

## Change for Snow

- Visual styling
- Mascot character
- child-safety controls
