# Snow Mockup Notes

## Established mockup direction

The Snow mockups use:

- large rounded white panels
- pastel winter gradients
- left sidebar with Snow logo
- top nav with Home, Learn, Explore, Rewards, Create
- right support panel when useful
- Snow mascot as the emotional anchor
- child name Minh and level chip
- parent access button
- snow hut illustration in sidebar bottom

## AI Companion mockup correction

The correct AI Companion direction is not a chat dashboard.

Correct direction:

- left settings panel
- center 2D companion stage
- large Snow character
- classroom/background scene
- subtitle overlay
- bottom mic/input controls
- optional compact chat history

## Design target

The UI should look buildable from Open LLM VTuber source but rebranded into Snow.
