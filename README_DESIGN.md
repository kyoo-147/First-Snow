# Snow UI Governance Pack

This folder is the UI contract for building Snow as a child-safe AI learning companion using the Open LLM VTuber web interaction model as the foundation for the AI Companion screen.

The goal is not to code everything immediately. The goal is to make AI agents, designers, and developers follow one consistent product direction before implementation.

## Use this order

1. Read `00_HOW_TO_USE_WITH_AI.md`.
2. Read `01_DESIGN.md` for the visual and product direction.
3. Read `08_TOKENS.md` and `design-system/tokens.css` before writing UI code.
4. Read `05_ROUTE_MAP.md` before creating routes.
5. Read `06_AI_COMPANION_UI_SPEC.md` before touching the AI Companion screen.
6. Read `15_OPEN_LLM_VTUBER_COMPATIBILITY.md` before porting Open LLM VTuber UI or logic.
7. Read `13_IMPLEMENTATION_CHECKLIST.md` before opening a pull request.

## Core principle

Snow is not a normal chatbot dashboard. Snow is a child-safe 2D AI companion with a Live2D-style stage, gentle lessons, parent control, and calm learning routines.
